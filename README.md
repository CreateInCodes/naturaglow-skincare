# NaturaGlow Skincare Store (naturaglowskincare.com)

A professional, mobile-first organic luxury ecommerce website built for Indian businesses.

## ✨ Features
- **Pure Organic Aesthetics**: Designed with Sage Green (`#4A6B5B`), Warm Paper (`#FDFCF7`), and Soft Gold (`#D4AF37`).
- **Complete Store Pages**: Home, Shop (with category filters), Product Detail (PDP), Cart, Secure Checkout, About Us, and Contact & FAQ.
- **Simulated Indian Checkout**: Supports UPI QR Code scanning (GPay/PhonePe), Cash on Delivery (COD), and Card/Netbanking, with instant order confirmation and WhatsApp order message generator.
- **LocalStorage Cart**: Persistent shopping bag across pages and refreshes.
- **SEO Ready**: Proper meta tags, OpenGraph tags, and descriptive alt texts.

## 🛠️ Tech Stack
- Plain HTML5, CSS3, and Vanilla JavaScript.
- No build tools or frameworks required — open `index.html` directly in any browser or deploy instantly on GitHub Pages, Vercel, or Netlify.

## 🚀 Getting Started
Simply clone or download this repository and open `index.html` in your web browser!
